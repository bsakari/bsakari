## 📈 Engineering Philosophy

I believe good engineering is about more than getting software to work.

I prioritise:

- **Reliability:** Systems should behave predictably in production.
- **Scalability:** Architecture should accommodate growth without unnecessary complexity.
- **Performance:** Efficient queries, caching, resource utilisation, and response times matter.
- **Maintainability:** Code should be understandable, testable, and easy to evolve.
- **Security:** Systems should be designed with appropriate access controls and security boundaries.
- **Ownership:** Engineers should understand the systems they build, deploy, and maintain.
